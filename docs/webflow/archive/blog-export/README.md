# Blog export (read-only)

`blogs-2026-09-28.csv` is the CSV export of the Blogs collection on the client's current Webflow
site (collection `691f95ac81715cb6ca49824b`), taken on 2026-09-28. It is the source of the seed
data in `src/content/` (`posts.json`, `post-bodies.json`) and of the custom code inventory in
[`blog-custom-code.md`](../../blog-custom-code.md). Keep it unchanged: it's the only record of the
original bodies, including the custom code blocks removed during cleaning.

What was done with it is in [`cms.md`](../../cms.md) → Import from the current site.
